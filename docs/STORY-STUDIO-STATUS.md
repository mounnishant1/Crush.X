## What works locally

- Home **Your story (+)** and Create **Add story** enter the composer.
- User-selected JPEG/PNG/WebP/GIF and MP4/WebM are validated with the existing 100 MB media-size guard; imported media remains in memory for the session.
- A story may use one medium, a 2–4 item collage, or a color-only template. A manual location sticker and emoji stickers are supported.
- **12 sticker tools:** GIF (up to 12 MB), Poll, Questions, Quiz (correct-answer selection), Countdown, HTTPS Link, Add Yours (local prompt/photo), Emoji Slider (local value), Hashtag (display only), Date/Time (three formats), Photo sticker (local image up to 12 MB), and Frame (Classic, Polaroid, Neon). Poll/Quiz/Questions buttons, the slider and Add Yours photo picker work in the local preview. Stickers and frames are included in the exported PNG. These are not remotely interactive.
- **Language and writing:** English, Hindi, Hinglish, Punjabi (Gurmukhi), and Haryanvi typed text, accessible language selection, OS spelling support, and four curated offline caption ideas per language. The writing ideas are labeled offline and **not** generated by an AURA-X model. No automatic translation/transliteration.
- **Typography:** 24 named browser-font presets (with device fallbacks), bold/italic/outline/shadow/gradient/neon toggles, size/position/rotation/scale, pointer drag, and typing/bounce/fade/slide preview animations. Some installed fonts may fall back. Animation is not encoded in PNG.
- Music may be previewed from a locally selected audio file up to 20 MB. Manual lyrics (user-owned text) can appear on the story and in a PNG, but automatic synchronized lyrics and the soundtrack are not embedded.
- Save downloads a composed **PNG preview**, including media frame, text, emojis, sticker card/photo/GIF still frame, overlays, optional frame, lyrics, mentions, filters and brush strokes if the browser permits drawing from the source. Videos and animated GIFs are exported only as still frames.
- Close discards this session's draft and revokes local object URLs. User content is not sent to an upload API.

## Known limits (do not describe as connected)

- **Publishing:** there is no verified upload destination, story backend, followers delivery or Close Friends server policy. Review explicitly blocks real sharing; the existing upload guard remains in place.
- **Mentions:** selections refer to local sample profiles. They are not delivered, and the repost toggle does not change another user's permissions.
- **Music:** no licensed catalog, music search or server-side media mixing.
- **Interactive stickers:** Poll/Quiz/Questions, Countdown and Emoji Slider run in the browser preview; Add Yours does not solicit community submissions; Hashtag does not open a discovery feed. No server responses, vote aggregation, DMs, follower notifications, or interactive PNG actions. HTTPS links open in the draft preview but become ordinary text when exported to PNG. Photo stickers and animated GIFs export as still images.
- **Languages and writing:** phrases are hand-authored offline samples, not language-model output or verified spelling corrections. Fonts differ by platform. Animated text is preview-only; a PNG stores a still frame.
- **Restyle and AI label:** restyle is a manual background picker; the AI label is self-declared, not an authenticity detector or image-generation feature.
- **Gallery:** browsers cannot enumerate a phone gallery or third-party album provider without user authorization/integration. Sample media may refuse PNG export because of cross-origin image policy; locally selected files are recommended.
- **Verification:** `node tests/home-ui.cjs`, `node tests/story-editor.cjs`, and JS syntax checks pass. Full Playwright tests are blocked in this environment because Chromium is not installed. Physical mobile-device UI testing, media/audio playback, and a verified backend integration remain pending.
