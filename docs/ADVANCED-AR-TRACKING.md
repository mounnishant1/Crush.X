# Tracking implementation and integration boundary

IMPLEMENTED: the AR Foundation 6.0.8 provider retains one stable `TrackableId`, snapshots pose and measured local mesh width on `ARFace.updated`, and removes its event subscription on face/manager changes, pause, disable and destruction. Event receipt uses `Time.realtimeSinceStartupAsDouble`; it is not a sensor exposure timestamp. Re-polling the snapshot does not refresh it. Android ARCore capabilities remain pose/mesh only when the active descriptor supports them. `Confidence=1` represents `TrackingState.Tracking`, not a measured probability (`ConfidenceIsMeasured=false`). No front-camera capability is inferred from this provider.

IMPLEMENTED: `TrackingSampleGate` rejects old, repeated, out-of-order, future and nonfinite observations, expires frozen results, and identifies changes requiring interpolation reset. `FaceTrackingManager` rejects invalid positions and zero/nonfinite rotations, normalizes valid rotations, smooths pose/mesh width/expressions, snaps after identity changes or reacquisition, and clears on lifecycle/provider transitions. A provider exception still permits tracking expiry. Width is accepted only within 0.08–0.25 metres and is not shared across identities.

## Genuine expressions

`face.Expressions.TryGet(ExpressionSignal.MouthOpen, out float value)` is the consumer API. False means unavailable, including a missing channel, invalid coefficient or expired inference. Zero is a valid measured coefficient. BlinkLeft/BlinkRight, SmileLeft/SmileRight, BrowRaiseLeft/BrowRaiseRight and per-eye gaze axes are separate channels. Combined Blink requires both eyes and takes the minimum, so a wink cannot become a bilateral blink; Smile/BrowRaise average two valid sides. The legacy MouthOpen/Blink fields are derived only from valid channels.

`BlendshapeExpressionMapper` maps canonical local model outputs: jawOpen, eyeBlinkLeft/Right, mouthSmileLeft/Right, browInnerUp with browOuterUpLeft/Right, and eyeLookIn/Out/Up/DownLeft/Right. Brow raise is the maximum of inner/outer coefficients on each side. Gaze is a normalized coefficient difference, positive X toward the subject's anatomical left and positive Y upward; this is not a calibrated fixation point or emotion classifier. Inputs must be finite within [0,1]. Mapping does not allocate per frame.

`BlendshapeTrackingProvider` decorates a genuine pose provider with a MonoBehaviour implementing `IOnDeviceBlendshapeSource`. Its output must contain a known matching `FaceIdentity`, coefficients, model confidence and capture-associated timestamp in the same monotonic clock. The runner must explicitly associate the model face with the AR face; a MediaPipe face index is not an AR TrackableId. Default IDs, excessive time skew, stale or malformed outputs cannot add an Expressions capability. The decorator owns no camera and performs no inference. Assign it using `FaceTrackingManager.SetProvider` only after a local runner exists; no absent runner is auto-installed or selected. Source dictionaries must remain stable during the read, and the runner must marshal native callbacks safely.
